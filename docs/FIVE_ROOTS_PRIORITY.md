# Five Roots → SKU / post priority

Use **MM_Integration_v4.html** (Integration Map): each **Root** (Name It · Burn It · Examine It · Tend It · Root It) rolls up to a **content pillar**, then **product SKUs**, then an **ancestral anchor**.

Before shipping a new post or SKU:

1. Name the Root it serves.
2. Confirm the pillar is not orphaned (no product or post path).
3. Check `lib/brandAssets.js` and service copy for visual/voice alignment.

This is a **prioritization filter**, not a separate codebase.
