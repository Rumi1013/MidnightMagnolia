# 90-day onboarding outline

- Week 1: systems access, classification training, and intake shadowing.
- Week 2: supervised intake ownership for one program area.
- Weeks 3-4: independent intake ownership and stakeholder-meeting exposure.
- Day 60: workflow-improvement recommendation.
- Day 90: formal review and next-quarter goals.

Every SOP should have a one-page quick reference and a short recorded walkthrough when feasible.
