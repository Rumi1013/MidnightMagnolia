# Privacy boundaries

| Boundary | Includes | Publication rule |
|---|---|---|
| Public | Approved directory entries, appropriate historical archive records, public event information | May be displayed after required review |
| Internal | Workflow status, operational notes, research queues, issue logs | Staff access only |
| Restricted | Submitter contact, living-person data, sensitive notes, credentials, legal correspondence | Named-role access only; never public by default |

Cross-project data movement requires a documented purpose, minimum necessary fields, and approval when sensitive data is involved.
