# Project brief — Magnolia Roots Digital Archive

| Field | Entry |
|---|---|
| Problem | Vincent/Vinson research lives in Supabase people/relationship tables and an Obsidian vault. That is not yet a public archive with sources, assertions, contribution review, or a research-request path. |
| Users | Public visitors searching deceased/historical individuals. Relatives offering a source or correction. Clients requesting scoped research. Researchers reviewing contributions. |
| Public boundary | Deceased/historical names approved for display, public relationships, citations, verification status, research notes written for the public. |
| Internal boundary | Research queue, contribution review, client-request status, unresolved hypotheses, next sources to search. |
| Restricted data | Living-person records, submitter contact, client contact, private notes, attachments not cleared for publication. |
| MVP features | Privacy rules before import. Relational schema beside — not instead of — `genealogy_people`. Sanitized starter line of deceased ancestors. Contribution and research-request forms stay pending. |
| Owner | Latisha Vincent-Waters |
| Success signal | A living person cannot appear in a public listing by default. Facts and unresolved claims stay distinguishable. The Obsidian vault is not seeded from `genealogy_people`. |
| Out of scope | Flattening the archive into one family-tree table. Auto-publishing a contribution. Institute or Press data in the same schema. |
| Status | Planned. Weeks 5–8. Schema file exists as planned SQL only. |
| Case-study spine | Challenge → Role → Architecture → Build → Governance → Outcome. Outcome is **planned**. |
