# Five Roots content filter (Integration v4)

Before shipping a new SKU or long post, pass it through:

**Root → pillar → product → ancestral anchor**

Roots (Integration Map): **Name It · Burn It · Examine It · Tend It · Root It.**

- Name which Root the piece serves.  
- Tie to one **content pillar** and one **product** (if commerce).  
- Name one **ancestral anchor** (lineage, place, or practice) so the work stays grounded.
